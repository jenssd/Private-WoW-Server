# Schamane – starke Endgame-Sets für Level 60, 70 und 80

Kuratierte Ausrüstungspakete für einen privaten AzerothCore-WotLK-3.3.5a-Server.

Enthalten:

- Elementar und Verstärkung
- Level 60, 70 und 80
- Tier-Set beziehungsweise sinnvoller Setbonus
- Hals, Rücken, Handgelenke, Gürtel und Stiefel
- zwei Ringe
- zwei Schmuckstücke
- Haupt- und Nebenhand
- Totem/Relikt
- fertige `.additem`-Blöcke

## Wichtige Einordnung

Eine mathematisch absolut eindeutige BiS-Liste existiert nicht für jede Situation. Sie hängt unter anderem ab von:

- Trefferwertung und vorhandenen Buffs
- Horde oder Allianz
- Einzelziel oder Flächenschaden
- Bossart und Kampfdauer
- Berufen und verfügbaren Verzauberungen
- verwendeter Talentverteilung
- Servermodulen und lokalen Datenbankänderungen

Die folgenden Listen sind deshalb als **sehr starke, sofort nutzbare Endgame-Sets** gedacht.

Für Level 80 orientieren sie sich an ICC/Ruby-Sanctum-Endgame-Ausrüstung.  
Für Level 70 wird Tier 6 mit Sunwell-Zubehör verwendet.  
Für Level 60 wird klassische Raid-Ausrüstung verwendet, aber unter den Mechaniken deines WotLK-Servers.

Vor dem Hinzufügen kannst du jede ID prüfen:

```text
/pwai <ITEM-ID>
```

oder:

```text
.lookup item <Name>
```

# IDs vor dem Ausgeben lokal kontrollieren

## Im Addon

```text
/pwai 51237
/pwai 34331
/pwai 21372
```

## Mit AzerothCore

```text
.lookup item Sanctified Frost Witch
.lookup item Skyshatter
.lookup item Stormcaller
```

## Direkt per MySQL

```sql
SELECT
    entry,
    name,
    RequiredLevel,
    InventoryType,
    Quality
FROM item_template
WHERE entry IN (
    51237,
    34331,
    21372
);
```

## Alle IDs eines Sets in einem SQL-Aufruf prüfen

Beispiel für Level 80 Elementar:

```sql
SELECT entry, name, RequiredLevel
FROM item_template
WHERE entry IN (
    51237, 50698, 54583, 51239, 54582, 51238,
    54587, 51236, 50699, 50658, 50664, 50398,
    50348, 50365, 50734, 50616, 50458
)
ORDER BY RequiredLevel, name;
```

# Ausrüstung anlegen

Die `.additem`-Befehle legen Gegenstände nur ins Inventar. Sie werden nicht automatisch angezogen.

Vorher:

```text
/cleartarget
```

Danach die Gegenstände manuell anlegen.

Bei zwei gleichen oder ähnlichen Einhandwaffen kontrollieren:

- Haupthand- oder Nebenhandbeschränkung
- Waffentyp
- Angriffsgeschwindigkeit
- benötigte Waffenfertigkeit
- Talent für beidhändiges Kämpfen

---

# Trefferwertung und Verzauberungen

Ein komplettes Endgame-Set ist nicht automatisch für jede Talentverteilung exakt am Trefferlimit.

Elementar priorisiert grundsätzlich:

1. erforderliche Zaubertrefferwertung
2. Zaubermacht
3. Tempowertung
4. kritische Trefferwertung

Verstärkung priorisiert typischerweise:

1. ausreichende Trefferwertung
2. Waffenkunde
3. Angriffskraft und Beweglichkeit
4. Tempowertung
5. kritische Trefferwertung

Auf einem privaten Singleplayer-Server ist ein leichtes Überschreiten der Caps meist weniger problematisch als auf einem streng optimierten Raidserver.
